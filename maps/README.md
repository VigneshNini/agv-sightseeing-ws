# Maps Directory

This directory holds navigation maps for the AGV Sightseeing Vehicle.

## 2D Occupancy Grid Maps (nav2_map_server format)
- `<name>.pgm` — grayscale occupancy image
- `<name>.yaml` — metadata (resolution, origin, thresholds)

Generate while mapping:
```bash
ros2 run nav2_map_server map_saver_cli -f maps/park_map
```

## 3D Point Cloud Maps (.pcd)
Generated by `ndt_mapping_node`. Load path configured via `agv_params.yaml`.

## YAML Reference
```yaml
image: park_map.pgm
resolution: 0.05
origin: [0.0, 0.0, 0.0]
occupied_thresh: 0.65
free_thresh: 0.25
```
